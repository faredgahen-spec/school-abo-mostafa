# بوابة مدرسة أبو مصطفى الثانوية المشتركة 🎓

منظومة إلكترونية متكاملة للاستعلام عن النتائج وكنترول المعلم المربوطة بسحابة **Firebase Firestore**.

---

## 📁 هيكل المشروع

```plaintext
school/
├── index.html               # بوابة الدخول الموحدة (اختيار الصفة: طالب أو معلم مشرف)
├── student-results.html     # بوابة استعلام الطلاب وعرض الشهادة المعتمدة وطباعتها PDF
├── teacher-dashboard.html   # لوحة تحكم المعلم المشرف ورصد الدرجات وإدارة الطلاب
├── start.bat                # تشغيل الخادم المحلي وفتح البوابة بضغطة زر
├── server.js                # خادم محلي خفيف مبني بـ Node.js
├── css/
│   └── style.css            # ملف التنسيقات العامة والطباعة والخطوط
├── js/
│   ├── firebase-config.js   # تكوين واتصال Firebase Firestore & Analytics
│   ├── gateway.js           # منطق التوجيه والتحقق من كود المشرف
│   ├── student.js           # الاستعلام عن النتيجة وعرض درجات الـ 9 مواد
│   └── teacher.js           # رصد وحفظ وتعديل وحذف الطلاب في فايربيز لحظياً
└── _1, _2, _3/              # الصفحات الأصلية مع تحديث الروابط
```

---

## 🚀 كيفية التشغيل

1. **الطريقة المباشرة (تشغيل الخادم المحلي):**
   - اضغط مرتين على ملف `start.bat`.
   - سيتم فتح المتصفح تلقائياً على الرابط: `http://localhost:3000`

2. **أو عبر سطر الأوامر:**
   ```bash
   node server.js
   ```

## ⚡ مميزات الربط مع Firebase

- **قاعدة بيانات Firestore الحية:** يتم حفظ وتحديث وحذف الطلاب في مجموعة `students` مباشرة.
- **تحديث لحظي (Real-time Sync):** أي طالب يسجله المعلم يظهر فوراً في القائمة ويكون متاحاً فوراً للاستعلام في صفحة الطالب.
- **حساب تلقائي للنسبة والتقدير:** لجميع المواد التسع (مجموع 420 درجة).
- **طباعة الشهادة الرسمية:** إمكانية طباعة تقرير درجات رسمي بتنسيق معد للطباعة وشهادة معتمدة.
